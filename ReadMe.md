This project uses teachable machines to help identify the authorship of human handwriting based upon a corpus of archival images. Given that I have roughly 450 images of handwritten texts, I wanted to create a program that would help me to identify the whether the author of the text was Charles Jencks, the primary subject of the archive, or someone else besides Jencks. To do this, I provided the machine with two labeled categories. One category contains 250 images of handwriting known to be written by Charles Jencks. The other category contains approximately 75 images that are known to be written by an author other than Charles Jencks. I then tested to see if the model was able to predict whether a text was written by Jencks by providing it additional images that from outside the training data. From my testing, the model appears to predict the author of the text with a good amount of accuracy.
